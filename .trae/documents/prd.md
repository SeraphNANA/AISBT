# AISBT AI 认知段位趣味测试 - 产品需求文档

## 1. 产品概述

AISBT 是一款对标 SBTI 搞怪人格测试的 AI 认知段位趣味测试产品，结合 MBTI 性格绑定与 AI 专业 L1-L9 能力分级。产品定位为纯前端静态网页，无后端、无数据库、不收集任何用户隐私数据，可直接 GitHub Pages 免费部署。

**核心价值**：
- 娱乐属性：复刻 SBTI 自嘲玩梗、搞怪人设、社交分享
- 专业属性：真实测试用户对 AI 的认知、使用能力、行业常识
- 绑定属性：MBTI 类型 + AI 等级联动，差异化人设解读

## 2. 核心功能

### 2.1 用户角色

无用户角色区分，所有访客均可直接使用，无需注册登录。

### 2.2 功能模块

1. **首页**：MBTI 类型选择、项目介绍、开始测试入口
2. **答题页**：题目渲染、选项交互、进度展示
3. **结果页**：AI 段位展示、人设解读、分享功能

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | Hero 区域 | 项目标题、简介文案、视觉氛围 |
| 首页 | MBTI 选择器 | 16 型人格下拉选择（INTJ/ENFP/INFP 等） |
| 首页 | 开始按钮 | 进入答题页的入口 |
| 答题页 | 进度条 | 显示当前题目进度（x/25） |
| 答题页 | 题目卡片 | 单选题展示、选项点击交互 |
| 答题页 | 导航按钮 | 上一题/下一题/提交按钮 |
| 结果页 | 段位展示 | L1-L9 等级 + 搞怪称号大标题 |
| 结果页 | 配图占位 | 方形图片预留位置 |
| 结果页 | 能力解读 | 专业能力评级 + AI 能力吐槽解读 |
| 结果页 | 性格联动 | MBTI 性格联动解读文案 |
| 结果页 | 操作按钮 | 一键复制结果、重新测试 |

## 3. 核心流程

用户进入首页 → 选择 MBTI 类型 → 点击开始测试 → 进入答题页（25 题）→ 答题完成自动计分 → 判定 L1-L9 等级 → 匹配 3 套人设文案之一 → 展示结果页 → 支持复制分享或重新测试

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色背景 + 霓虹渐变点缀（赛博朋克/科技感）
- **辅助色**：紫色、青色、粉色渐变，营造 AI 未来感
- **按钮风格**：圆角胶囊按钮，渐变背景，hover 发光效果
- **字体**：标题使用粗体无衬线字体，正文使用清晰易读字体
- **布局风格**：卡片式布局，居中对齐，移动端优先
- **图标/Emoji**：适度使用科技感图标，避免过度装饰

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | Hero 区域 | 深色背景、渐变标题、动态粒子/光效背景 |
| 首页 | MBTI 选择器 | 下拉菜单、圆角边框、选中高亮 |
| 首页 | 开始按钮 | 胶囊按钮、渐变背景、hover 放大发光 |
| 答题页 | 进度条 | 顶部细长进度条、渐变填充 |
| 答题页 | 题目卡片 | 圆角卡片、选项 hover 高亮、选中状态明显 |
| 答题页 | 导航按钮 | 底部固定、上一题/下一题/提交 |
| 结果页 | 段位展示 | 大号标题、渐变文字、动画入场 |
| 结果页 | 配图占位 | 方形占位框、虚线边框、提示文字 |
| 结果页 | 解读模块 | 分块卡片、图标点缀、渐变边框 |
| 结果页 | 操作按钮 | 复制按钮、重新测试按钮、hover 效果 |

### 4.3 响应式设计

- **桌面优先**：主要针对桌面端设计，保证大屏体验
- **移动端适配**：375px 起适配，触控友好
- **触控优化**：按钮/选项点击区域足够大（最小 44px）

### 4.4 动效设计

- **页面切换**：淡入淡出 + 轻微位移
- **题目切换**：卡片滑入动画
- **结果展示**：分段依次入场（标题 → 配图 → 解读 → 按钮）
- **交互反馈**：按钮 hover 放大、选项选中动画

## 5. 题目与分级体系

### 5.1 题目设计

- **总题数**：25 题（18 道专业题 + 7 道趣味题）
- **题型**：全部单选题
- **专业题分类**：
  - AI 基础概念（Token/大模型/RAG/Agent）
  - 主流工具认知（Liblib/星流/各类大模型区别）
  - AI 使用常识、提示词认知、版权商用常识
- **趣味题风格**：SBTI 风格无厘头提问、使用 AI 的习惯、脑洞假设题

### 5.2 计分规则

- 每题固定分值，专业题分值高、趣味题分值低
- 总分区间映射 L1～L9 固定等级

### 5.3 分级体系

| 等级 | 称号 | 人群定位 |
|-----|------|---------|
| L1 | 门外小白 | 完全不懂 AI，只当聊天工具 |
| L2 | 入门萌新 | 听说过 AI，偶尔使用 |
| L3 | 初级玩家 | 会用几个 AI 工具 |
| L4 | 进阶用户 | 了解 AI 基础概念 |
| L5 | 熟练操作者 | 日常使用 AI 辅助工作 |
| L6 | 深度用户 | 理解模型原理 |
| L7 | 专业玩家 | 掌握 Prompt 工程 |
| L8 | 高阶工程师 | 能做模型微调/部署 |
| L9 | AI 大神 | 行业专家级别 |

### 5.4 人设匹配规则

每个 L 等级配置 3 套人设文案，根据 MBTI 属性自动匹配：
- **I 人（内向）**：匹配低调佛系、躺平型文案
- **E 人（外向）**：匹配爱玩爱聊、社交型文案
- **理性型 MBTI**：匹配理智较真、钻研型文案

## 6. 技术约束

- **纯前端**：无后端服务器、无数据库、无 API 请求
- **隐私安全**：不收集任何用户数据，页面刷新无数据留存
- **配置分离**：题库、分值、等级文案、人设解读全部抽离成 JSON 配置文件
- **开源部署**：支持 GitHub Pages 静态部署
