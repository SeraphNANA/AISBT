## ⚡ 动态难度调整算法

### 升级规则
- **触发条件**：当前等级连续答对2道
- **升级效果**：下一题自动切换到更高难度的题目
- **示例**：L1连续对2道 → 自动进入L2难度题目

### 降级规则
- **触发条件**：答错1道
- **降级效果**：恢复到较低难度的题目
- **示例**：L3答错1道 → 回到L2或L1难度题目

### 难度梯度表

```
简单梯度（L1-L3）：
L1 → L2 → L3 → ...
  ↑
  | 连续对2道
  |
  
中等梯度（L4-L6）：
L4 → L5 → L6 → ...
  ↑
  | 连续对2道（L3全部答对）
  |
  
困难梯度（L7-L9）：
L7 → L8 → L9
  ↑
  | 连续对2道（L6全部答对）
  |
```

## 🎲 随机性设计

### 题目随机抽取
- 每个等级有5-7道备选题
- 测试时从题库池中随机抽取
- 保证每次测试题目不完全相同

### 趣味题随机
- 30道趣味题备选库
- 每次测试随机抽取6道
- 包含话题性、争议性、娱乐性内容

### 答案分布
- 正确答案随机分布在A/B/C/D四个选项
- 避免规律性答案
- 确保测试公平性

## 📋 测试流程

```
1. 选择MBTI类型
   ↓
2. 生成测试题库（L1-L9随机抽取19道专业题 + 6道趣味题）
   ↓
3. 按L1→L2→L3→...→L9顺序答题
   ↓
4. 每答一题记录答案
   ↓
5. 连续对2道触发升级（L1→L2）
   ↓
6. 答错则降级或保持
   ↓
7. 答完25道题计算总分
   ↓
8. 根据分数判定等级（L1-L9）
   ↓
9. 匹配MBTI对应的E人/I人角色
   ↓
10. 显示结果和角色图片
```

## 💡 设计亮点

1. **难度渐进**：题目由易到难，符合学习曲线
2. **动态调整**：根据正确率自动调整难度
3. **随机性**：每次测试题目不完全相同
4. **公平性**：答案随机分布，无规律可循
5. **可玩性**：趣味题增加娱乐性，避免枯燥
